Contrato do control plane

Interface mínima para novos módulos enviarem dados ao cérebro.

window.GeneralManagerBridge.publishEvent({ system: 'marketing-place', type: 'customer_created', severity: 'info', message: 'Novo cliente cadastrado', entityId: 'cliente-id' });

O evento é registrado localmente e, quando autorizado, na coleção systemEvents. O gestor também escuta o evento browser manager:system-event.

Princípios de segurança

O arquivo funciona como console; a autorização real precisa estar no backend/regras.

i
Importante para produção enterprise

Não confie somente na interface para proteger dados. Use Firebase Authentication, custom claims, regras do Firestore e, para ações privilegiadas, uma camada server-side. O gestor registra a intenção e a evidência; a política deve negar por padrão.
